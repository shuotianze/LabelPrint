NIIMBOT B1 标签打印工具。Windows 桌面版 + Android 手机版，通过蓝牙 BLE 直连打印机，不经过手机 App 中转。

## 下载哪个

| 文件 | 适用 | 说明 |
|---|---|---|
| `LabelPrint_0.1.0_x64-setup.exe` | Windows | **推荐**。安装包，双击装到本机 |
| `label-app.exe` | Windows | 免安装单文件，双击直接跑 |
| `LabelPrint_0.1.0_x64_en-US.msi` | Windows | MSI 包，适合批量部署 |
| `LabelPrint_0.1.0_arm64.apk` | Android | 已签名，Android 8.0+，仅 arm64 |

## 功能

- **模板**：12 套内置模板（快递面单、仓位标签、线缆标签、资产标签等），可增删改
- **以中间点为基准的横向布局**：属性面板直接改「中心 X」，元素按中间线对称伸缩；宽 30 和宽 50 的元素能对齐到同一条中心线
- **清晰度**：文字 3 倍超采样 + 覆盖率落墨，解决加粗/小字发虚、边缘灰边描边
- **纸张**：位图宽度按纸宽实算（48 mm = 384 点，50 mm = 400 点），换纸型整版等比缩放
- **条码 / 二维码**：CODE128、EAN-13、CODE39、ITF、UPC 等，明文单独渲染，不会被切底
- **蓝牙**：niimbluelib 直连，扫描 / 连接 / 打图 / 走纸 / 查电量固件
- **手机布局**：单栏 + 左侧抽屉 + 底部属性面板，画布按屏幕宽度自动拟合

## 安装说明

**Windows**：双击 `setup.exe`。安装向导是英文（Tauri 默认），装完程序名是「标签打印」。

**Android**：把 APK 传到手机后点击安装，系统会要求允许「安装未知来源应用」。首次扫描打印机时手机会弹蓝牙权限申请，**必须允许**，否则扫不到任何设备（安卓 12+ 的行为，不弹窗也不报错）。

## 已知限制

- 安卓包只含 `arm64-v8a`，2020 年以后的主流机型都支持；老 32 位设备装不上
- 界面目前只有中文
- 打印宽度实测可满 50 mm；若某台机器右边被切，在属性面板把打印头点数改回 384 点（48 mm）

## 从源码构建

见仓库 README 的「跑起来」一节。

```bash
npm install
npm run dist                                    # Windows 安装包
npx tauri android build --apk --target aarch64  # Android（需自备 JDK 17 + SDK + NDK 27，并自行签名）
```
