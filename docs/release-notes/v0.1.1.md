模板交互重构 + 手机端修复。NIIMBOT B1 标签打印工具，Windows 桌面版 + Android 手机版，蓝牙 BLE 直连打印机。

## 下载哪个

| 文件 | 适用 | 说明 |
|---|---|---|
| `LabelPrint_0.1.1_x64-setup.exe` | Windows | **推荐**。安装包，双击装到本机 |
| `labelprint-0.1.1-portable.exe` | Windows | 免安装单文件，双击直接跑 |
| `LabelPrint_0.1.1_x64_en-US.msi` | Windows | MSI 包，适合批量部署 |
| `LabelPrint-0.1.1.apk` | Android | 已签名，Android 8.0+，仅 arm64 |

## 本版更新

- **模板移到编辑页**：手机端模板改成编辑页顶部的卡片行（带缩略图、当前模板高亮），不用进侧栏；默认收起，点「全部」展开
- **存模板不再依赖系统弹窗**：改用页内输入面板（安卓 WebView 里 window.prompt 直接失效），支持另存 / 覆盖同名 / 重命名 / 复制 / 删除（二次确认）/ 一键更新当前模板
- **最近使用置顶**；本地模板标注纸型，套用内置模板只换排版不动纸张，套用本地模板连纸张一起恢复
- **多选**：手机上轻点逐个加选，再点一下已选中的就取消它，点空白全部取消；长按也能单独加选/减选
- **修复**：手机端白屏（removeChild NotFoundError）、双击文字标签崩溃、打包沿用旧前端缓存导致"改了不生效"的问题

## 安装说明

**Windows**：双击 `setup.exe`。安装向导是英文（Tauri 默认），装完程序名是「标签打印」。

**Android**：把 APK 传到手机后点击安装，系统会要求允许「安装未知来源应用」。首次扫描打印机时会弹蓝牙权限申请，**必须允许**，否则扫不到任何设备（安卓 12+ 的行为）。
