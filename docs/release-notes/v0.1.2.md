手机端编辑体验修正：预览画布放大到好用的大小。

## 下载哪个

| 文件 | 适用 | 说明 |
|---|---|---|
| `LabelPrint_0.1.2_x64-setup.exe` | Windows | **推荐**。安装包，双击装到本机 |
| `labelprint-0.1.2-portable.exe` | Windows | 免安装单文件，双击直接跑 |
| `LabelPrint_0.1.2_x64_en-US.msi` | Windows | MSI 包，适合批量部署 |
| `LabelPrint-0.1.2.apk` | Android | 已签名，Android 8.0+，仅 arm64 |

## 本版更新

- **预览放大**：手机上画布从"整页塞进屏幕"（约 0.85 倍，字小难选中）改为"横向填满再放大 1.4 倍"，文字和元素更好点、更好拖
- 放大后超出预览卡片的部分改为**卡片内部滑动查看**，页面本身不动，底部打印栏不会跟着跑
- 极端小屏或超宽纸张自动退回"整页放下"，不会放大到只剩一角

## 与 0.1.1 相同

模板卡片行、页内保存面板、多选轻点切换等交互沿用 0.1.1，详见 [0.1.1 发版说明](https://github.com/shuotianze/LabelPrint/releases/tag/v0.1.1)。

## 校验

- 安卓 APK：v2+v3 签名（与 0.1.1 同证书，可直接覆盖安装），versionCode 1002
- 冒烟测试 110 项、单元测试 17 项全通过

## 已知限制

- 安卓包只含 `arm64-v8a`，老 32 位设备装不上
- 界面目前只有中文
